# MiCita Salud

## Descripción
Proyecto de modelado de requisitos funcionales mediante UML para la plataforma MiCita Salud.

## Integrante
- Juan Felipe Larrotta Ramirez

## Herramienta utilizada
- StarUML

## Objetivo
Representar mediante un diagrama de casos de uso las principales funcionalidades de la plataforma MiCita Salud.

## Funcionalidades principales
- Registro y autenticación de pacientes.
- Consulta de disponibilidad de citas.
- Solicitud, cancelación y reprogramación de citas.
- Gestión de agendas médicas.
- Registro de evolución médica.
- Generación de órdenes médicas.
- Procesamiento de pagos.
- Envío de recordatorios.
- Administración de usuarios y roles.
